INSTALLAZIONE APPAPP INSTALLATION

Fai comparire TPOS come una vera app.Make TPOS appear like a real app.

TPOS è una web app: non serve App Store o Play Store. Una volta aggiunta alla Home avrà la sua icona e si aprirà a schermo intero.TPOS is a web app: you do not need the App Store or Play Store. Once added to your Home Screen it gets its own icon and opens full screen.

TPOS
Apri la pagina di installazione dal dispositivo su cui vuoi usare TPOS.Open the installation page on the device where you want to use TPOS.

La pagina riconosce automaticamente iPhone/iPad o Android e mostra la procedura corretta.The page automatically detects iPhone/iPad or Android and shows the correct procedure.

02
TENNISTALKER COMPANION

Importa i dati da TennisTalker senza ricopiarli a mano.Import TennisTalker data without copying it by hand.

Il Companion aggiunge direttamente nelle pagine TennisTalker i comandi per trasferire ranking, profili giocatore e storico match al modulo Opponents di TPOS.The Companion adds controls directly inside TennisTalker pages to send rankings, player profiles and match history to the TPOS Opponents module.

Installazione manuale BetaManual Beta installation

Finché Google non approva l'estensione, si installa una volta manualmente.Until Google approves the extension, install it manually once.

Quando sarà pubblicata sul Chrome Web Store questa procedura diventerà un normale “Aggiungi a Chrome”.Once it is published on the Chrome Web Store, this will become a normal “Add to Chrome” flow.

Apri download CompanionOpen Companion download
↓

Installazione manualeManual installation

  1. Premi Scarica Companion e scarica il pacchetto ZIP.Press Download Companion and download the ZIP package.
  2. Decomprimi lo ZIP in una cartella che non sposterai.Unzip it into a folder you will not move.
  3. Apri Chrome → Estensioni → Gestisci estensioni.Open Chrome → Extensions → Manage extensions.
  4. Attiva Modalità sviluppatore in alto a destra.Enable Developer mode at the top right.
  5. Premi Carica estensione non pacchettizzata e seleziona la cartella estratta.Press Load unpacked and select the extracted folder.
  6. Ricarica una volta sia TennisTalker sia Tennis Player OS.Reload both TennisTalker and Tennis Player OS once.
↗

Dopo l'installazioneAfter installation

  1. Accedi normalmente a TennisTalker in Chrome.Sign in to TennisTalker normally in Chrome.
  2. Apri la classifica o il profilo che vuoi importare.Open the ranking or player profile you want to import.
  3. Usa il pannello Tennis Player OS che compare nella pagina.Use the Tennis Player OS panel that appears on the page.
  4. TPOS si apre su Opponents e ti mostra i dati prima di confermare l'importazione.TPOS opens Opponents and shows the data before you confirm the import.
Privacy

Il Companion non legge né salva la password TennisTalker: usa la sessione che hai già aperto nel browser. I dati temporanei vengono rimossi al termine o all'annullamento dell'importazione.The Companion does not read or save your TennisTalker password: it uses the browser session you already opened. Temporary import data is removed when the import completes or is cancelled.

Se il pannello TPOS non compare su TennisTalkerIf the TPOS panel does not appear on TennisTalker

Controlla che il Companion sia attivo in Chrome → Estensioni, poi ricarica la pagina TennisTalker. Se hai più profili Chrome, verifica di aver installato l'estensione nello stesso profilo con cui stai navigando.Check that the Companion is enabled in Chrome → Extensions, then reload the TennisTalker page. If you use multiple Chrome profiles, make sure you installed it in the same profile you are browsing with.
